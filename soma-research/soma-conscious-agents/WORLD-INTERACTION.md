# Operational World Interaction

An external world declares observation, action, and feedback channels. A codec may encode syntax such as coordinates or tokens, but cannot provide segmentation, symmetry classes, latent causes, or answer rules.

The matrix adapter emits `extent`, `coordinate`, `successor`, and scalar `incidence` relations. Matrix decoding exists only inside the sealed evaluator. Cognitive modules import neither `MatrixCodec` nor benchmark names.

The public `LearningView` contains demonstrations and query observations. The private evaluator stores query answers and exposes only commitments. Induction, program execution, headset construction, conscious-agent transition, and action commitment all happen before the one allowed reveal.

The inducer first infers a general finite relational signature. It then constructs candidate observer carriers, contextual roles, connectivity closures, quotients, and correspondences. Each candidate headset transforms the boundary before the paired relational program is scored. Programs are compositions of the universal typed calculus; there is no matrix, periodicity, symmetry group, object class, or benchmark operation in the cognitive vocabulary.

For interactive sources, a generic `trace_json` instrument supplies measured state-action-next-state edges. The same joint hypothesis contains the learned Markov transition model, goal posterior, and policy type. Planning scores predicted utility, information gain, reversibility, and observed action cost. Unseen transitions remain explicitly unseen.

Every hypothesis is replayed on public demonstrations and evaluated leave-one-out with learned parameters rebuilt from the remaining examples. The code prior is an explicit prefix length. The hypothesis transition kernel uses reversible local program edits. Predictions on unanswered queries are used to compute posterior disagreement for experiment ordering.

The selected program is executed into a typed action. A conscious agent with closed `P`, `D`, and `A` maps then produces that world action through `Q = DAP`. Its observer process is an exact trace of the larger computation process. A policy-gated RTL law alternates between the full and traced experience spaces.

After commitment, exact external evaluation becomes a feedback event. It reweights the same hypothesis posterior, changes the headset and RTL digest, and is persisted with the selected program, posterior, policy, headset state, episodes, and autobiography. A later compatible world can reuse the typed program and prior; the report records whether transfer occurred.

A report separates:

- `integration_complete`: all causal and formal architecture witnesses passed;
- `external_task_solved`: all sealed committed actions matched exactly.

A task failure remains a valid experimental result. The runtime does not insert a missing task transformation after feedback.
