# Evidence Boundary

## External sources

- Human odor priming trials and ratings from the OSF repository associated with DOI `10.1016/j.foodqual.2024.105227`. Manifests pin the files by SHA-256 and declare row filters before validation.
- Official ARC-AGI-2 evaluation tasks `0934a4d8`, `135a2760`, and `136b0064` from repository commit `f3283f727488ad98fe575ea6a5ac981e4a188e49`.
- Public Bell and QND-tomography archives retained with repository metadata for later preregistered experiments. The current validation does not consume them.

## Empirical measurements

The odor suite uses only recorded external rows. It reports source counts, exact provenance digests, finite transition counts, empirical probabilities, and a conservative finite-sample error certificate. Reported odor ratings describe human reports; they do not identify an experience with a molecule, receptor, neural state, or word.

## External interaction measurements

`integration_complete` means that the relational protocol, answer sealing, program posterior, headset, conscious-agent transition, exact trace, variable-space RTL, program-bound commitment, feedback revision, persistence, and causal provenance checks passed.

`external_task_solved` means that the already committed action exactly matched the answer revealed by the evaluator. Both fields are true for the first two task reports. Because both task answers were available during implementation and debugging, these are post-development regression results. They do not measure untouched-task generalization.

Task `136b0064` was checksum-pinned and executed once before its grids were
inspected. It failed with zero resolved public replay cells and an incorrect
query action type. This is the current independent evidence about
generalization and is retained without a post-result rerun.

## Formal results

Kernel normalization, `Q = DAP`, agent-network closure, trace decomposition and transitivity, stationary restriction, experience-space morphisms, proposal-kernel detailed balance, prefix coding, automorphism consensus, causal-graph validation, and persistence are mathematical or software invariants of the finite implementation. They are not empirical evidence for consciousness, AGI, quantum theory, spacetime, or cosmology.

## Required next evidence

A generalization claim requires a preregistered untouched task set, fixed resource limits and success criteria, no implementation changes after task access, and complete reporting of every attempt. A physics claim additionally requires an explicit derivation from the agent/trace law and independent real-world observations that distinguish it from existing models.
